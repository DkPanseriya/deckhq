Start with the number.

Before you install anything, run the report. Ten seconds, a few hundred kilobytes, and it sends nothing and writes nothing.

npx deckhq doctor

  transcripts     77 sessions across 20 projects

  on the floor    77  ← 71 sessions have already finished; the agent view no longer lists them
  codex           not installed

  hooks           installed, port 4400, 285 events, last 1m ago

  egress          none. no outbound sockets.

The fourth line is the number nobody else counts: sessions that finished their turn, left the agent view when their process exited, and are still on the floor, because a session finishing is not the same as you having dealt with it.

A real run on the development machine, 3 September 2026. Your numbers will differ, and that is the point: nobody knows this number about their own machine until they run the command.

The one rule

What you owe is decided by you, never by the runtime.

What a session is doing changes on its own: it starts, it types, it blocks, it goes quiet, it exits. What you owe it changes only when you press a button. Reading a message does not clear it, and neither does the session finishing.

What it never does

  • Send your code anywhere

    Your conversations, your file names and your diffs stay on the machine. No analytics, no telemetry, no update check, no cloud.

  • Ask who you are

    No account, no sign-in, no licence key. Every theme and every feature is there on the first run.

  • Touch your Claude settings

    Not until you have read the exact lines it would add and said yes. It backs the file up first, and it removes only what it put there.

  • Decide what you owe

    Reading a message does not clear it. No session ending and no test passing clears your queue; an action of yours does.

  • Get in your way

    Your shell prompt stays live the whole time. DeckHQ runs beside your work and never between you and it.

On macOS a downloaded file arrives without its run bit, so the first run needs chmod +x ~/Downloads/Install-DeckHQ.command in Terminal.

  • You already have Node

    Downloads the package, runs it, leaves no binary behind. It opens the floor in a window of its own.

    npx deckhq app

  • Windows, no Node

    Checks for Node, offers to install it with winget, never without asking, then installs DeckHQ and opens it.

    irm https://dkpanseriya.github.io/deckhq/install.ps1 | iex

  • macOS and Linux, no Node

    The same script for a POSIX shell: brew on macOS, your distribution’s own command printed for you on Linux.

    curl -fsSL https://dkpanseriya.github.io/deckhq/install.sh | sh
