The fourth line is the number nobody else counts: sessions that finished their turn, left the agent view when their process exited, and are still on the floor, because a session finishing is not the same as you having dealt with it.

A real run on the development machine, 3 September 2026. Your numbers will differ, and that is the point: nobody knows this number about their own machine until they run the command.

The one rule

What you owe is decided by you, never by the runtime.

activityState is observed: it changes on its own as a session starts, produces output, blocks, goes quiet, exits. ackState is yours, and it changes only when you press a button. The model in 60 seconds is the whole of it.

What it never does

  • Call anything

    No analytics, no update check, no CDN. The only sockets are loopback and the runtimes you start yourself.

  • Ask who you are

    There is no account, no sign-in and no licence key. Every theme and every feature is there on the first run.

  • Decide what you owe

    Reading an item does not discharge it. No session ending and no test passing clears your queue; an action of yours does.

  • Block your terminal

    The prompt in your shell stays live the whole time. A closed DeckHQ can never stop anybody from working.

  • Write without asking

    Hooks, the status line, the Desktop icon: each prints the literal file and the exact path first, and removes only what it wrote.

Three ways in.

Node 18 or newer, and nothing else. No build step, no runtime dependency, no account.

  • You already have Node

    Downloads the package, runs it, leaves no binary behind. It opens the floor in a window of its own.

    npx deckhq app

  • Windows, no Node

    Checks for Node, offers to install it with winget, never without asking, then installs DeckHQ and opens it.

    irm https://dkpanseriya.github.io/deckhq/install.ps1 | iex

  • macOS and Linux, no Node

    The same script for a POSIX shell: brew on macOS, your distribution’s own command printed for you on Linux.

    curl -fsSL https://dkpanseriya.github.io/deckhq/install.sh | sh

Read a script before you pipe it into a shell, these two included. They are served from this site byte for byte as they are in the repository: install.ps1, install.sh. There is also a global install, a Claude Code plugin and a VS Code extension. All four routes are here.
