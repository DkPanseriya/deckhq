Questions.

The ones DeckHQ gets asked, answered once each.

Which coding tools does it read?

Claude Code is verified: reading, replying, streamed sends, hooks, and a permission prompt answered from the panel. Codex is verified for reading and replying.

Gemini CLI and OpenCode adapters exist and are unverified: they are written against each tool's documented format and have never been run against real data. Each says so on its own label in the app.

Do I have to start my agents from DeckHQ?

No. Start them anywhere: a terminal, your editor, the desktop app. DeckHQ reads the sessions already on your disk, and they turn up on the floor.

You can start one from it too: + New agent in the header, or the + in a room.

What does it cost?

Nothing. DeckHQ is free and MIT licensed, with no account and no licence check.

Does anything leave my machine?

No. It binds 127.0.0.1 and nothing else, and makes no outbound connection: no analytics, no telemetry, no update check. The last line of deckhq doctor reads egress none. no outbound sockets.

What it never does

What happens when I close the window?

DeckHQ keeps counting. The window is a view; the queue is kept on disk in ~/.deckhq/, and it is still there tomorrow if you do not deal with it. deckhq waiting prints the same queue in a terminal.

How is a raised hand different from a red badge?

A raised hand means the session is mid-task and blocked on a question only you can answer. A red badge with a time means it finished its turn and wants a review. Both wait in Your Office, and the header counts them separately.

Without the hooks, a transcript alone does not tell a blocked session from a stopped one, and the header says so.

Does it write to my Claude Code settings?

Only if you ask it to install hooks, and then it shows you the exact JSON and the exact file and asks first. It backs the file up, tags what it wrote, and removes only what it tagged. The plugin route writes nothing there at all.

Can it stop or kill a session?

No. Benching takes a session out of your queue. Firing takes it off the floor and keeps its chat. Neither touches the process, and a closed DeckHQ blocks nobody.

Does it work on macOS and Linux?

The floor, the queue and the terminal commands run on all three, and every change is tested on each. Four things have been run on Windows only so far: the app window's installers, opening a session in a terminal, Go to session, and OS notifications.

Why tokens and not dollars?

Most people run these tools on a subscription, so dollars are one setting away and off by default. Turn Show cost on and you get a list-price estimate with the date of its rate card. A model with no price reads no rate.

Something is wrong. Where do I say so?

Open an issue with the output of deckhq doctor --share, which takes paths, project names and the machine name out first.
