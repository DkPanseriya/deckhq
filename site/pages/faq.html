FAQ

Ten questions, answered with what has actually been run on a machine. Where something has not been, the answer says so.

Does DeckHQ send my code anywhere?

No. Nothing leaves your machine: no analytics, no telemetry, no update check, no crash reports, no cloud. Your conversations, file names and diffs are read off your own disk and stay there. The last line of npx deckhq doctor reports what it found going out, and the answer is nothing. Privacy and security has the rest.

Which coding tools does it work with?

Claude Code and Codex are the two that have been run against real sessions. Claude Code gets everything: reading, replying, live state and answering a permission prompt from the panel. Codex is read and replied to, without the live state.

Gemini CLI and OpenCode are written against each tool’s published format and have never been run against real data, because neither is installed on the machine DeckHQ is built on. They say so in the app rather than pretending otherwise.

Do I need an account?

No. There is no sign-up, no sign-in, no licence key and no email address to hand over. Install it and it works, with every theme and every feature on from the first run.

Is it free? Will it stay free?

MIT, and the thing on your machine stays that way. Paid services are planned above it — the kind that need a server, like one floor across several machines — and they are things you would opt into. The floor, the queue and every action on it stay free, and the free product keeps making no outbound connection at all.

Windows, macOS or Linux?

All three, on Node 18 or newer, tested on each of them on every change. Two things are honest exceptions: “open in terminal” has only ever been run for real on Windows, and the same goes for system notifications. The macOS and Linux versions of both are written against each system’s own documentation and have not been executed on one.

Does it run my agents, or cost me tokens?

Neither. You start your sessions where you always start them, and they turn up on the floor because their transcripts are on the disk. DeckHQ starts nothing of its own, and nothing on the floor costs a token to be there.

Is the cost number my bill?

No. DeckHQ counts the tokens it can see and multiplies them by public list prices, so you can compare one project against another. It has no idea what your plan charges you, and it is labelled an estimate everywhere it appears. Dollars are off until you turn them on.

How do I update it?

npx deckhq app fetches the current version every time, so there is nothing to do. If you installed it globally, npm install -g deckhq@latest. DeckHQ never checks for updates on its own and never nags you about one.

How do I uninstall it?

If you used npx, there is nothing to undo. Otherwise npm uninstall -g deckhq. If you turned on the status line or let DeckHQ add hooks to Claude Code, take those out from the app or with deckhq statusline --remove --yes; each removes only the lines it added. Then delete ~/.deckhq/, and nothing of DeckHQ is left on the machine.

Do I have to keep a window open?

No, and you should not have to. DeckHQ keeps counting while you are not looking, because that is when work piles up. deckhq waiting answers from the terminal, deckhq statusline puts ▣ 3 waiting · 1 hand up in your status bar, and an installed DeckHQ badges its dock icon with the count while every window is shut.

Something is wrong. Where do I say so?

Issues, with the output of deckhq doctor --share if it is about your machine — that block has your paths, project names and machine name taken out of it already. A security problem has its own route: Privacy and security. What shipped and when is on the changelog.
