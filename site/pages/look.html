The look.

Three finishes ship today, all free and none of them gated. Each one repaints materials and neutrals; the six state colours never move, so a raised hand is the same amber in all three.

One populated floor per theme is a committed golden. A theme that quietly failed to reach the bake would fail CI on the next run.

The same room, three times.

Ground, wood, fabric and light change. The plate stays legible, every ink keeps its contrast floor, and the working green on the agents is the same green in all three.

Coming: Look.

Interior presets, a picker for ground, carpet, wood, fabric and plants, and an agent size that the furniture scales with. None of it is built. The three pictures below are the drawings it is designed against, and they are labelled as drawings.

Whatever ships has to pass what a theme passes today: assertThemeContrast, assertMaterialDiscipline and the figure-halo guard, on every combination. Agent size changes no geometry — the same population draws the same room rectangles at every setting.

Packs

Extra themes and avatar sets arrive as a single signed file. deckhq pack install <file> copies it into ~/.deckhq/packs/ and a running DeckHQ picks it up within a second. A pack carries colours and names and nothing else: there is no key in its format for a tier, a licence, an expiry or a feature flag, and a test runs the whole API surface with and without one installed and diffs the responses.

Every theme in a pack goes through the same contrast gates as a theme DeckHQ ships, and every avatar colour is held a fixed distance from every state colour, so an agent can never wear a state. There is no account and no network call anywhere in it.
