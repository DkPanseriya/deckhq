The characters

A session on the floor is a person at a desk. Its colour is its state, its face is its identity, and both have to read at 22 pixels from across the room. This page has what ships today, and then the sheets two unbuilt packages are designed against — every one of those labelled as the drawing it is.

What ships today

The state colour owns the whole body. Head included. An agent can never wear a state colour as identity, and identity can never borrow one: every avatar colour is held a fixed distance from all six state colours, checked rather than eyeballed.

Identity is a face, a name and sometimes a hat, derived from the session id, so the same session is the same person on every restart. The name comes from a pool of 600 and is kept for good; a number after a name is unreachable below 600 live identities on one machine.

Reduced motion is a first-class render, not a degradation. Under prefers-reduced-motion characters snap instead of walking, each clip holds one representative pose, and the floor stays fully legible — with a golden proving it.

How that figure was chosen

Four candidates were drawn as full sheets — sizes, states, identity, in situ — and put on the same lounge crop at 1:1, 34 pixels tall, because the argument is only settled at the size the floor actually draws.

B won: a 45° three-quarter robot, symmetric and front-facing, so all six poses read from any scan direction, and the bright visor is the most findable element on the floor. It maps cleanly onto the skeleton the rig already had.

The sheets below are the proposal, not the product. The figure that shipped is in the golden above; every golden in the repository changed when it landed.

Coming in WP-87: the ways it moves

The figure can stand six ways and move none. WP-87 gives it a thinking cloud, a working clip, a run cycle, and the lounge activities a benched agent has nothing to do without — games, coffee, a conversation.

None of it is built. The two sheets below are what it is designed against, and they are rendered by scripts in this repository from the same drawing code the floor uses, which makes them faithful and does not make them screenshots.

What already binds it: one static frame per state under prefers-reduced-motion with a golden proving it, and every phase from the injected clock rather than the wall clock, so a capture of a moving floor is reproducible.

Coming in WP-89: the crew

A session that spawns sub-agents should show them. WP-89 draws three or more live sub-agents smaller on the floor around their parent, each with a laptop, joined by cables carrying data pulses back toward the parent desk, arriving and leaving with the sub-agents themselves.

Not built. The animation below is a drawing of it. Today sub-agents are on the floor as juniors beside their parent, without the cables.

The honesty constraint is already fixed: a cable is a claim about a parent–child relationship, so where the link is inferred rather than observed no cable is drawn. Juniors never enter the needs-you count unless they raise a hand themselves.

The mark

DeckHQ’s own icon lives once, as a hand-written SVG — six rounded rectangles, both grounds in one file, no font and no external reference — and every PNG, the favicon.ico and the VS Code tile are rendered from it by a script that rasterises the shapes itself rather than driving a browser. A test compares the committed files against a fresh render on every run, so the source and its outputs cannot drift apart.
