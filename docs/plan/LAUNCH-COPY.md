
**Privacy read, line by line, before reuse.** No filesystem path, no project name, no machine name,
no user name, no hook port, no session id, no model id, no message text. `state` says `writable`
where the full `doctor` prints `~/.deckhq/state.json, writable`; `hooks` drops the port the full
`doctor` shows. The date is the only thing in it that is about this machine at all. It is safe to
paste and it was checked rather than assumed.

**Two live conditions on the sample.** `waiting on you` reads `needs a running DeckHQ to count`
because no daemon was up for this run; a reader who runs the floor first gets a number there.
`hooks installed, NOTHING LISTENING THERE` is the same condition seen from the hooks side. Before
any wave, re-run with a daemon up so the reader sees the row that carries the product, and re-check
the fourth line against the current Claude Code build (`08` §3.0.1).

**Line numbering, which the copy depends on.** In `npx deckhq doctor` the fourth printed line is
`on the floor`. In `--share` a dated header line comes first, so the same line is fifth. The
"post your fourth line" ask is therefore written against plain `doctor`, and every post that uses
it names that command.

## 4. Reply templates for the open threads

**Word count: 260** (three templates: 87, 85, 88).
**Channel constraints respected:** each is under 90 words, help comes first and the link comes last
and once, per `02` §4 Wave 0. Each is a template, not a paste: the first sentence is rewritten to

### 4.1 For "I have too many sessions and lose track of them"

> Two things that helped me before I built anything. `claude agents` will tell you what is running
> right now, and it is faster than tabbing through terminals. For the ones that already exited,
> the transcripts are all still on disk under `~/.claude/projects/` as JSONL, one file per session,
> newest mtime first — a two-line `ls -t` gets you a list of what you were actually doing this
> week. If you want that as a standing view rather than a command, I wrote DeckHQ:
> github.com/DkPanseriya/deckhq. MIT, local, no telemetry.

### 4.2 For "how do I know which session is waiting on me"

> You have to decide what "waiting" means before a tool can answer, because the runtimes only
> report what is running. If you want it today: Claude Code hooks fire on
> `Stop` and `Notification`, and a four-line hook that appends to a file gives you a log of every
> turn that ended and every prompt that went up. That log is the thing you actually want. If you
> would rather not write it, DeckHQ does exactly that and keeps the item until you clear it:
> github.com/DkPanseriya/deckhq.

### 4.3 For "I want this, but not another tool phoning home"

> Fair, and worth checking rather than taking anyone's word for. Run whatever you are considering
> with `lsof -i` or a proxy beside it for ten minutes and watch what it opens, and read its
> analytics setting before you touch it rather than after. That is a five-minute test and it
> settles the question for any tool, this one included. For what it is worth, DeckHQ makes no
> outbound calls at all, has zero dependencies, and `npx deckhq doctor` prints the egress it found
> as its last line: github.com/DkPanseriya/deckhq.

## 5. When asked about X

**Word count: 183** (four answers, two sentences each).
**Rule these obey:** `02` §7 and `08` §3.5 — never compare in public. These are answers to a
question someone else asked, never a post, and no sentence in them claims anything about another
tool that has not been measured. Each is two sentences. If pressed further, the answer is "run both
and see", not an argument.

**Munder Difflin.** Munder Difflin runs your agents: you talk to it, and it starts them. DeckHQ
starts nothing — it reads the transcripts already on your disk, so sessions you began in any
terminal turn up, and what they are owed survives the process exiting.

**Pixel Agents.** Pixel Agents is a visualiser, and a good-looking one. DeckHQ is built to be
closed: the status line, `deckhq waiting` in a terminal and the day's card all exist so that not
looking at it is safe.

**Claude Code's own agent view.** It lists what Claude Code is running, and on this machine on
4 September it reported 6 while DeckHQ counted 83 on the floor. The 77 in between are sessions that
finished their turn and exited, and DeckHQ keeps them plus whatever they still need from you.

**Happy and Remote Control.** Both put your phone on a live session, both are free, and if that is
what you want then use them. DeckHQ is a different job on one machine: every session on the floor at
once, and an acknowledgement that only you can clear.
